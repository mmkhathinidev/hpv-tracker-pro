# Icons Directory

This directory contains 16x16 PNG icon files for the HPV Sample Tracker application.

## Supported Icons

The application will look for the following icon files:

- `add.png` - Add sample button
- `edit.png` - Edit sample functionality
- `delete.png` - Delete sample button
- `search.png` - Search functionality
- `export.png` - General export functionality
- `import.png` - Import CSV button
- `backup.png` - Backup data button
- `reset.png` - Reset all data button
- `csv.png` - CSV export button
- `pdf.png` - PDF export button
- `docx.png` - DOCX export button
- `database.png` - Import database button

## Icon Requirements

- Format: PNG
- Size: 16x16 pixels (will be resized if different)
- Transparency: Supported
- Color: Any (should work well with the application theme)

## Usage

Icons are loaded automatically when the application starts. If an icon file is not found, the button will display without an icon. The application will work perfectly with or without icons.

## Adding Icons

To add icons:
1. Place 16x16 PNG files in this directory
2. Name them according to the list above
3. Restart the application to see the icons
